## วิธีเปิดใช้งาน

**เปิดจากเครื่องโดยตรง:** ดับเบิลคลิก `index.html`

**อัปขึ้น GitHub Pages:**

1. สร้าง repository ใหม่บน github.com ตั้งเป็น **Public**
2. อัปโหลดไฟล์ทั้ง 8 ไฟล์ในโฟลเดอร์นี้ขึ้นไป (ลากทั้งหมดพร้อมกันได้)
3. ไปที่ **Settings → Pages**
4. Source เลือก **Deploy from a branch** → branch `main` → folder `/ (root)` → **Save**
5. รอ 1–2 นาที แล้วรีเฟรช จะได้ลิงก์แบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

ส่งลิงก์นั้นให้น้องได้เลย เปิดจากมือถือหรือคอมที่บ้านได้
